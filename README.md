## 📌 Project Overview

This project analyzes student placement data to identify the factors that influence placement success. Interactive dashboards were developed to uncover trends and provide recommendations for improving placement outcomes.

---

## 🎯 Objectives

- Analyze placement trends.
- Identify factors affecting placements.
- Build interactive dashboards.
- Generate actionable recommendations.

---

## 📂 Dataset

| Attribute | Description |
|-----------|-------------|
| Students | Placement Records |
| Features | CGPA, Skills, Internships, Aptitude, Communication, Placement Status |

## 📈 Dashboard Includes

- Placement Rate

- Skills vs Placement
- Internship Analysis
- Department-wise Placement

---

## 🔍 Key Insights

- Higher CGPA generally improved placement chances.
- Students with internships had better placement rates.
- Strong technical skills correlated with successful placements.
- Certain departments achieved higher placement percentages.

---

## 💼 Recommendations

- Encourage internship participation.
- Strengthen technical skill development.
- Increase industry collaboration.
- Conduct placement-focused training sessions.
